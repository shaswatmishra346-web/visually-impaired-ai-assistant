# Components Directory

This directory contains reusable UI widgets and components.

## Components:
- `CameraStream.js` - Handles camera input and video frame streaming
- `ObjectDetectionDisplay.js` - Visualizes detected objects with bounding boxes
- `OCRDisplay.js` - Shows recognized text from OCR processing
- `SceneDescription.js` - Displays scene descriptions from VLM
- `AudioControls.js` - Manages audio playback and TTS output
- `EmergencyAlert.js` - Displays priority emergency alerts
- `SettingsPanel.js` - User configurable settings interface
