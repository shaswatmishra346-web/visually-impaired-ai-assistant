# Hooks Directory

This directory contains custom React hooks for WebSocket connections and audio synthesis.

## Hooks:
- `useWebSocket.js` - Manages WebSocket connection for real-time video streaming
- `useAudio.js` - Handles audio synthesis and playback using Web Audio API
- `useInference.js` - Manages inference requests and response handling
- `useCamera.js` - Handles camera access and frame capture
- `useNotifications.js` - Manages audio notifications and alerts
