# Models Module

This module contains ONNX and PyTorch model wrappers for inference.

## Files:
- `onnx_model.py` - Wrapper for ONNX models (YOLO for object detection)
- `pytorch_model.py` - Wrapper for PyTorch/Transformer models (VLM for scene understanding)
- `model_manager.py` - Manages model loading, caching, and inference scheduling
