# API Module

This module contains FastAPI routers for different endpoints.

## Files:
- `websocket.py` - WebSocket endpoints for real-time video frame streaming
- `inference.py` - REST endpoints for triggering inference tasks
- `ocr.py` - REST endpoints for OCR processing
- `vlm.py` - REST endpoints for Vision-Language Model scene understanding
- `auth.py` - Authentication and authorization endpoints
